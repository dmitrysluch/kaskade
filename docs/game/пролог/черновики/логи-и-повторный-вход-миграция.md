# Миграция: логи и повторный вход

Статус: задача после реализации контракта
[[../../07-оболочка-тз#Лог контекста и повторный вход]]. Авторское правило —
[[../../05-тексты-и-документы#Повторный вход в сцену]].

## Движок

1. Разрешить `log: true|false` во frontmatter `scene` и `room`. Для виртуальной
   комнаты наследовать значение общей части и разрешить stage-версии его
   перекрыть.
2. Разобрать `## reentry` как зарезервированный текстовый фрагмент, а не ноду
   графа. Запретить ссылки, атрибуты, эффекты, опции и маршруты внутри него.
3. Сохранять семантические блоки основного потока: прозу, цитаты, реплики со
   speaker id, эхо команд, системные сообщения и разметку сущностей. Не
   сохранять экранные переносы, опции, preview, ввод, курсор, прокрутку,
   сплэши и оверлеи.
4. Буфер активного контекста сохранять независимо от `log`, чтобы reload
   возвращал тот же поток. При настоящем уходе удалять его, если `log: true` не
   задан; при приостановке для будущего `resume` не удалять.
5. Реализовать неявный `resume` без новой разметки. Закрытие предмета или
   оверлея и возврат сцены в вызвавший контекст сохраняют видимый поток, не
   повторяют вступление или текущую ноду, не исполняют `reentry` и только
   пересчитывают опции. Если сцена явно возвращает другую ноду той же комнаты,
   проиграть только эту ноду. При уходе по другому логическому адресу
   приостановленный контекст перестаёт быть возвратным.
6. При настоящем повторном входе восстановить лог без анимации и побочных
   эффектов, затем проиграть `reentry`, если он есть. После этого пересчитать
   опции из обычного состояния. Reload входом не считать.
7. Ключевать комнаты по `(episode, stage, persistent)`, сцены — по
   `(episode, stage, scene id)`. Старые ключи после смены stage хранить, но не
   подмешивать в новый контекст.
8. Добавить `logs{}` в сейв, повысить `saveVersion` и мигрировать отсутствие
   поля в `{}`. При первой загрузке такого сейва разрешить `reentry` активного
   контекста как точку восстановления. Существующие логи при последующих
   обновлениях не переписывать и не обрезать.
9. Добавить предупреждение для доказуемо повторно достижимого **не через
   `resume`** контекста без `log: true` и `reentry`; отдельного предупреждения
   или требования разметки для `resume` не добавлять. Остальные нарушения
   контракта сделать ошибками.

## Контент пролога

После поддержки движком провести аудит всех активных `scenes/` и итоговых
виртуальных комнат. Не добавлять `reentry` линейным one-shot-сценам только ради
единообразия.

| Контекст | Миграция |
|---|---|
| `scenes/00-talk` | `log: true` и `reentry`: «Тоби оборачивается к тебе.» |
| `scenes/00-student-talk` | `log: true`; проверить повторный вход в хаб после обеих тональных веток и после `prolog.student-offended` |
| `scenes/00-librarian-talk` → `rooms-virt/tu.library` | считать неявным `resume`: после выдачи книги не повторять описание библиотеки и мысль про пуфик |
| `scenes/03-invite` | `log: true`: вызовы отдельных реплик из секретариата должны собираться в один разговорный лог; отдельный `reentry` не нужен |
| `scenes/00-intro`, `00-night`, `01-lecture`, `01-after-lecture`, `02-*`, `03-arrival`, `03-kitchen`, `03-leave`, `03-talk` | оставить без `log` и `reentry`, пока они остаются линейными и недостижимыми повторно |
| `scenes/00-study` | не логировать диспетчер мини-игр; возврат продолжает первую непройденную мини-игру по её собственному состоянию |
| Общие источники проходимых комнат TU и общежития | добавить `log: true` в `common-*`, чтобы все stage наследовали историю помещения |
| `rooms/01-h1012`, `rooms/03-living-room` и другие проходимые комнаты без общей части | добавить `log: true` непосредственно в stage-файл |
| Закрытые будущие `common-*` | не включать механически; добавить `log` одновременно с первым доступным stage |

После миграции удалить комментарии, которые объясняют пустой поток или
повторное непечатание описания как желаемое поведение. Пустой входной диспетчер
комнаты остаётся: он выбирает состояние, а лог отвечает только за то, что уже
видел игрок.

## Приёмка

- Выйти из `00-talk` в комнату, а затем снова выполнить `говорить с Тоби`:
  старый разговор восстановлен, затем появляется новая реакция Тоби;
  `once`-ветки не исполняются повторно.
- Закрыть предмет, справочник, «Дело» и инвентарь: лог и прокрутка основного
  контекста возвращаются без `reentry`.
- Забрать учебник у библиотекарши: после сообщения инвентаря сразу доступны
  команды библиотеки; описание помещения и мысль Марго не печатаются повторно.
- Вернуться из сцены в явно указанную новую ноду вызывающей комнаты: печатается
  только новая нода, `reentry` комнаты не исполняется.
- Перезагрузить вкладку посреди логируемой сцены: виден прежний поток и
  актуальные опции, но новая реакция на вход не печатается.
- Перезагрузить вкладку в контексте только с `reentry`, без `log: true`:
  активный буфер восстановлен, `reentry` не дублируется.
- Вернуться в логируемую комнату после обхода соседних помещений: её история
  восстановлена, доступные предметы и переходы соответствуют текущим флагам.
- Перейти в новый stage той же `persistent`-комнаты: старый текст не показан,
  но остаётся в `logs{}` сейва.
- Загрузить старый сейв без `logs`: он мигрирует с пустым объектом и использует
  `reentry`, где тот написан.
- Изменить ширину окна перед загрузкой: сохранённый текст переносится заново,
  без строк от старой сетки.
- Обновить текст сцены после сохранения: старый лог остаётся дословной историей,
  новый текст используется только для ещё не сыгранных узлов.
