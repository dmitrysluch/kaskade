# Тот же скоп, что `03-corridor`: ни карточки перехода, ни `location`.
# **Комната, а не сцена.** Раньше секретарь сама выкладывала про день рождения,
# и игрок только нажимал одну кнопку. Теперь конверт лежит на стойке как
# предмет: Марго его замечает и спрашивает сама.
# Два узла, и второй — без текста. Описание печатается один раз, при входе;
# разговор идёт из `#стойка`, и реплики возвращаются туда же, а не во
# вступление — иначе описание комнаты перепечатывалось бы после каждой фразы.
# Это тот же приём, что хаб разговора в `00-talk`, только хаб стоит в комнате.
# Больше состояний нет намеренно: меняется не описание, а набор доступного,
# и это работа `if` на опциях. Состояния в `01-hall` заведены потому, что там
# меняется содержимое аудитории.
# Коробки из-под бумаги стоят у ксерокса с первой строки описания — чтобы
# `взять коробку` не выглядела вещью, появившейся ровно тогда, когда понадобилась.
# `взять коробку` требует одного флага `prolog.box-possible`, который ставится
# в `03-invite#коробка-можно`: там же сходятся оба условия — она знает про день
# рождения и слышала его реплику про коробки. Двух `if` на одной опции нет.
