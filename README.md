# Принято к сведению

Веб-игра в терминале. Оболочка по ТЗ из `game/07-оболочка-тз.md`.

```
npm install
npm run dev        # http://localhost:5178
```

Править заметки можно двумя способами. Открыть `content/` в Obsidian как vault —
тогда вкладка перерисовывается сама, позиция в сцене не теряется. Или писать
в основном vault (`Интерактив на ДР/game/пролог/`) и забирать оттуда:

```
npm run sync && npm run lint
```

Синхронизация односторонняя и зеркальная: удалённая в Obsidian заметка исчезает
и здесь. Соответствие папок задано в `пролог/00-карта.md`; `game.yaml`,
`episode.yaml`, `characters/` и `reference.yaml` живут только в репозитории
и синхронизацией не трогаются.

Ошибки контента приезжают в игру оверлеем — с именем файла и строкой.

## Команды

| | |
|---|---|
| `npm run sync` | забрать контент и ТЗ из Obsidian, вместе с удалениями |
| `npm run dev` | сервер + клиент на одном порту, watcher на `content/` |
| `npm run lint` | валидатор контента: дизайн-правила как автотесты |
| `npm test` | юнит-тесты парсера, генераторов, правил, каталога и сейва |
| `npm run typecheck` | tsc |
| `npm run frame` | печатает экран в терминал: `npm run frame -- <узел> "<ввод>"`, плюс `COLS=`, `ROWS=`, `SCROLL=` |
| `npm run smoke` | поднимает сервер, дёргает его и гасит |
| `npm run build` / `npm start` | прод-сборка и раздача |

## Где что

```
content/          vault: game.yaml, reference.yaml, words, docs, episodes, characters
app/shared/       типы контента и состояния — один файл на клиент и сервер
app/server/       express, парсер заметок, раскрытие генераторов, валидатор, watcher
app/client/       React: engine (каталог опций, автокомплит, состояние, сейв),
                  renderers (academic), ui (сетка знакомест, рамки, раскладка)
```

## Что уже есть

Пролог целиком: две сцены с титрами между ними, четыре комнаты, предметы,
командная строка с автокомплитом, три служебные команды и их хоткеи, портрет
Марго с переопределением палитры эпизодом, сейв в localStorage с миграциями,
рендерер `academic`.

Звук реализован, но файлов нет — отсутствие ресурса игру не ломает.

Экран — сетка знакомест: рамки нарисованы символами, перенос и ширину колонок
оболочка считает сама. `columns` в `game.yaml` — это ширина макета, а не жёсткий
размер: кегль подбирается так, чтобы столько знаков ровно легло в окно. История
копится в пределах сцены, листается `PgUp`/`PgDn`, и то, что осталось за краем,
показано стрелкой на рамке.
