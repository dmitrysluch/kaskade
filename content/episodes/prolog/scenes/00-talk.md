# Разговор устроен как комната ([[07-оболочка-тз]], «Диалог»): `#хаб` — узел без
# текста, темы это опции с `once`, каждая возвращает в хаб. Порядок выбирает
# игрок, обязательных тем нет, выход доступен с первой секунды.
# Сходиться разрешено только в хаб: внутри темы у каждого ответа свой узел.
# Правило вычитки: реплика должна быть понятна, если прочитать только её.
# Выходы из тем намеренно разной формы: где-то реплика, где-то ремарка,
# где-то он не отвечает вообще. Одинаковые двери делают ритм метрономом.
# Разметка ([[07-оболочка-тз]], «Кто говорит»): `> —` Тоби, `—` Марго,
# обычный абзац — ремарка. Метка опции — команда строчными, реплика Марго —
# первой строкой целевого узла.
# Флаги разговора:
#   prolog.pentest        назвала это тестом на проникновение
#   prolog.sharp          отвечала резко — вместе с pentest открывает тёмный ответ
#   prolog.ines           нашла устаревшую строчку про седьмой уровень
#   prolog.moscow         рассказала про рейс из Москвы — открывает Беломорканал
#   prolog.leverkusen     услышала про журнал приёмки, заполненный по запаху
#   prolog.soft-grunberg  промолчала на «ты почти наша»
#   prolog.soft-zoloft    промолчала на золофт
# Оба soft вместе дают единственную реплику, где Тоби вообще что-то замечает.
# Ветка про Леверкузен открывается только тем, кто осмотрел Тоби и видел наклейку.
