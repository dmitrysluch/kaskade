# Распутать мысль

Автономный прототип мини-игры для `00-study`: открой `index.html` в браузере. Сборка, сервер и подключение к интернету не нужны. Всё находится в одном HTML-файле.

- Перетаскивай точки мышью или пальцем, пока нити не перестанут пересекаться.
- Пока точка выбрана, её нити и соответствующие места в тексте подсвечены одинаковыми цветами и номерами. После отпускания подсветка исчезает.
- С клавиатуры: `Tab` / `Shift+Tab` выбирают точку, стрелки двигают её, `Shift` ускоряет движение, `Esc` снимает выделение. Во время перетаскивания `Esc` отменяет ход.
- «Отменить ход» возвращает предыдущую расстановку. «Другой клубок» создаёт новое поле и соответствие слов.
- Этапы сверху можно открывать в любом порядке. «Показать решение» позволяет быстро посмотреть восстановленный текст.
- На третьем этапе после распутывания появляется действие «Обвести “единственный”».

## Механика

На каждом этапе десять точек и двенадцать нитей. В каждом текстовом блоке — двенадцать слов или коротких фрагментов. Для каждого блока один раз выбирается случайное взаимно однозначное соответствие «нить → позиция в тексте».

Для отображения берётся копия исходного текста. Текущие пересечения обходятся в лексикографическом порядке пар ID нитей; каждое пересечение меняет содержимое двух соответствующих позиций. История движений не влияет на текст. Переключение одного пересечения меняет две позиции в каждом блоке; уменьшение числа пересечений не гарантирует монотонного роста читаемости.

Подсветка показывает постоянное соответствие нитей позициям, а не закрепляет цвет за конкретным словом: содержимое позиции меняется при перестановках. Номера помогают сопоставлять нити и слова без различения цветов.

Поле генерируется перемешиванием заведомо распутываемой расстановки. Начальный клубок подбирается так, чтобы переставленными оказались не меньше девяти из двенадцати текстовых позиций; на первом и третьем этапах — не меньше десяти. Общие концы нитей не считаются пересечениями. Наложение точек и попадание точки на чужую нить блокируют завершение. Победа фиксируется после отпускания точки, когда геометрия корректна, а не по совпадению текстов.

Тексты и вид прототипные. Настройка этапов — массив `STAGES`, цвета выбранных нитей — `COLORS`, соответствие и перестановки — `makePuzzle` и `permute` внутри `index.html`.
