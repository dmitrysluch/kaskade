Как устроен прототип

Каждой нити соответствует место в каждом блоке текста. Пересечение двух нитей меняет слова местами. Связи постоянны на весь этап; у каждого блока своя перестановка. Цвет и номер показывают соответствие, пока точка выбрана.

Текст каждый раз собирается из оригинала по текущим пересечениям. Этапы сверху можно открывать в любом порядке.
